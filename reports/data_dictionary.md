# E-Commerce Sales & Customer Analytics — Data Dictionary & Metric Catalog

## 1. Relational Database Tables

### 1.1 `categories`
| Column | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `category_id` | VARCHAR(20) | PRIMARY KEY | Unique identifier for product category (e.g. `CAT-001`) |
| `category_name` | VARCHAR(100) | NOT NULL | Commercial category name (e.g. `Smartphones & Mobile`) |
| `department` | VARCHAR(50) | NOT NULL | High-level department (`Electronics`, `Fashion`, `Home & Kitchen`, `Sports & Fitness`, `Beauty & Personal Care`, `Books & Office`) |
| `description` | TEXT | NULLABLE | Brief scope and description of product items in category |

### 1.2 `products`
| Column | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `product_id` | VARCHAR(20) | PRIMARY KEY | Unique product SKU identifier (e.g. `PRD-0001`) |
| `product_name` | VARCHAR(150) | NOT NULL | Commercial product name |
| `category_id` | VARCHAR(20) | FOREIGN KEY (`categories.category_id`) | Category reference |
| `unit_cost` | DECIMAL(10,2)| NOT NULL | Unit cost of goods sold (COGS) in USD |
| `unit_price` | DECIMAL(10,2)| NOT NULL | Retail list price in USD |
| `target_margin_pct` | DECIMAL(5,2) | NOT NULL | Standard retail margin percentage `((unit_price - unit_cost) / unit_price) * 100` |
| `is_active` | INTEGER | DEFAULT 1 | 1 = active, 0 = discontinued |

### 1.3 `customers`
| Column | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `customer_id` | VARCHAR(20) | PRIMARY KEY | Unique customer account ID (e.g. `CUST-00001`) |
| `first_name` | VARCHAR(50) | NOT NULL | Customer first name |
| `last_name` | VARCHAR(50) | NOT NULL | Customer last name |
| `email` | VARCHAR(100) | NOT NULL, UNIQUE | Customer contact email |
| `city` | VARCHAR(50) | NOT NULL | Delivery billing city |
| `state` | VARCHAR(50) | NOT NULL | Delivery billing US State code (e.g. `CA`, `NY`, `TX`) |
| `country` | VARCHAR(50) | DEFAULT 'United States' | Country of residence |
| `signup_date` | DATE | NOT NULL | Account creation date |
| `acquisition_channel` | VARCHAR(50) | NOT NULL | Acquisition attribution channel (`Organic Search`, `Paid Search`, `Social Media`, `Email Marketing`, `Affiliate Referral`) |
| `customer_tier` | VARCHAR(20) | DEFAULT 'Standard' | Loyalty tier (`Standard`, `Silver`, `Gold`, `Platinum`) |

### 1.4 `orders`
| Column | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_id` | VARCHAR(30) | PRIMARY KEY | Unique order transaction ID (e.g. `ORD-000001`) |
| `customer_id` | VARCHAR(20) | FOREIGN KEY (`customers.customer_id`) | Customer who placed the order |
| `order_date` | TIMESTAMP | NOT NULL | Date and time the order was placed |
| `order_status` | VARCHAR(20) | NOT NULL | Fulfillment state (`Completed`, `Shipped`, `Cancelled`, `Returned`) |
| `payment_method` | VARCHAR(30) | NOT NULL | Payment processor (`Credit Card`, `PayPal`, `Apple Pay`, `BNPL`) |
| `sales_channel` | VARCHAR(30) | NOT NULL | Ordering device/platform (`Web`, `Mobile App`, `Affiliate`) |
| `shipping_cost` | DECIMAL(10,2)| DEFAULT 0.00 | Shipping fee charged to customer in USD |
| `discount_amount` | DECIMAL(10,2)| DEFAULT 0.00 | Total discount applied across line items in USD |
| `total_amount` | DECIMAL(10,2)| NOT NULL | Net charged order amount including shipping in USD |

### 1.5 `order_items`
| Column | Data Type | Key / Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_item_id` | VARCHAR(40) | PRIMARY KEY | Unique order item line ID (e.g. `ITEM-0000001`) |
| `order_id` | VARCHAR(30) | FOREIGN KEY (`orders.order_id`) | Parent order reference |
| `product_id` | VARCHAR(20) | FOREIGN KEY (`products.product_id`) | Product SKU ordered |
| `quantity` | INTEGER | NOT NULL | Units purchased |
| `unit_price` | DECIMAL(10,2)| NOT NULL | Retail price per unit at time of purchase |
| `unit_cost` | DECIMAL(10,2)| NOT NULL | Cost per unit at time of purchase |
| `discount_applied` | DECIMAL(10,2)| DEFAULT 0.00 | Discount deducted from this line item |
| `total_item_price` | DECIMAL(10,2)| NOT NULL | `(quantity * unit_price) - discount_applied` |
| `gross_profit` | DECIMAL(10,2)| NOT NULL | `total_item_price - (quantity * unit_cost)` |

## 2. Core Analytical Metric Definitions

| Metric | Formula / Business Logic | Answering Question | Interpretation |
| :--- | :--- | :--- | :--- |
| **Gross Revenue** | `SUM(order_items.total_item_price)` for `Completed` orders | Q1, Q3 | Total top-line revenue generated by sales |
| **Net Gross Profit** | `SUM(order_items.gross_profit)` | Q1, Q3 | Revenue minus cost of goods sold |
| **Gross Margin %** | `(Gross Profit / Gross Revenue) * 100` | Q1 | Profitability efficiency percentage |
| **Pareto 80/20 Flag** | Cumulative Revenue % <= 80.0% | Q1 | Identifies the top products generating 80% of sales |
| **Average Order Value (AOV)** | `Gross Revenue / Total Completed Orders` | Q5 | Average ticket size per transaction |
| **MoM Sales Growth %** | `((Revenue_t - Revenue_{t-1}) / Revenue_{t-1}) * 100` | Q3 | Month-over-month trajectory velocity |
| **QoQ Category Growth %** | `((Q_Revenue_t - Q_Revenue_{t-1}) / Q_Revenue_{t-1}) * 100` | Q4 | Quarterly momentum of individual categories |
| **Recency (R)** | Days between last completed order and snapshot date | Q2, Q6 | Lower is better; indicates customer activity |
| **Frequency (F)** | Total count of distinct completed orders | Q2 | Higher indicates brand loyalty |
| **Monetary (M)** | Total lifetime spend across all completed orders | Q2 | Identifies financial weight of customer |
| **RFM Quintiles (1-5)** | `NTILE(5)` ranked distributions across R, F, M | Q2 | Standardized score where 555 is champion |
| **Cadence Latency Multiplier** | `Days Inactive / Average Days Between Orders` | Q6 | Ratio > 2.0 indicates abnormal delay |
| **Churn Risk Tier** | Heuristic evaluation of latency and spend | Q6 | Priority flag for marketing retention |
